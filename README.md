# Flores para Geysa Danitza

Jardín romántico interactivo, responsive y sin dependencias externas. Incluye flores amarillas, lotos, movimiento por toque o mouse y una carta dedicada a Geysa Danitza.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todo el contenido de esta carpeta.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **GitHub Actions**.
5. El flujo incluido publicará automáticamente el contenido de `dist/`.

También puedes probarlo localmente abriendo `dist/index.html` en el navegador.
